# Code of Conduct

## Our Standards

We commit to a respectful, harassment-free community. Constructive behavior
includes using welcoming language, respecting differing experience and views,
giving actionable technical feedback, accepting correction, and prioritizing the
community's safety over individual status.

Unacceptable behavior includes harassment, threats, sexualized attention,
discrimination, deliberate intimidation, sustained disruption, publishing
private information, or personal attacks. Technical disagreement is expected;
hostility is not.

## Enforcement

Report conduct concerns privately through the repository's GitHub private
vulnerability reporting channel and label the opening sentence as a code of
conduct report. If that channel is unavailable, open a minimal issue asking for
a private maintainer contact without naming involved people publicly.

Maintainers will protect reporter confidentiality as far as practical, assess
reports fairly, disclose relevant conflicts, and may remove content, issue a
warning, impose a temporary restriction, or permanently ban participation. A
maintainer named in a report must not adjudicate it. Retaliation against a good
faith reporter is prohibited.

This policy applies in project spaces and when someone is publicly representing
the project. Maintainers are responsible for clarifying and enforcing it.
